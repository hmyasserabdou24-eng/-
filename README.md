# مشروع تطبيق أندرويد فضاء أولياء دار الإحسان — Dar El Ihsan Parents Android

تطبيق Android أصيل ومستقل تماماً مخصص لأولياء أطفال المركز النفسي البيداغوجي دار الإحسان (العطف، ولاية غرداية).
تم تصميمه خصيصاً لتوفير تجربة مستقرة، آمنة ومستمرة للأولياء، مع ميزة تسجيل الدخول لمرة واحدة واستقبال إشعارات أندرويد الحقيقية (FCM) في كافة الحالات.

---

## 🌟 الميزات الجوهرية المنفذة:

### 1. عزل فضاء الأولياء نهائياً
- التطبيق يبدأ مباشرة بصفحة تسجيل دخول فضاء الأولياء (`parent.html`) وليس الموقع التعريفي العام.
- منع تام للوصول إلى لوحة الإدارة (`manage.html`) أو الموقع التعريفي (`site.html`) أو روابط الأرشيف.
- حظر أي إعادة توجيه داخلية أو خارجية تحاول نقله للوحة الإدارة.
- معالجة زر الرجوع (`OnBackPressedCallback`) بحيث لا يسمح إطلاقاً بالرجوع إلى صفحات الإدارة، وإنما يتنقل داخل تبويبات فضاء الأولياء فقط أو يؤكد الخروج من التطبيق.
- فتح روابط واتساب والاتصال الهاتفي مباشرة في التطبيقات الرسمية للهاتف (`Intent`).

### 2. تسجيل الدخول الدائم والآمن (Single Sign-On & Persistence)
- تسجيل الدخول لأول مرة فقط، واستمرار الجلسة حتى بعد إغلاق التطبيق أو إعادة تشغيل الهاتف.
- استخدام جلسة وتوكنات Supabase الرسمية دون استحداث نظام مصادقة بديل.
- حفظ الجلسة مشفرة عتادياً باستخدام `EncryptedSharedPreferences` ومفاتيح `MasterKey (AES-256 GCM)` عبر نظام Android Keystore.
- استعادة الجلسة والتحقق من صلاحيتها فور فتح التطبيق قبل إظهار شاشة الدخول.
- تجديد الجلسة تلقائياً عبر رمز التحديث (`refresh_token`) دون مقاطعة الولي ودون طلب كلمة المرور.
- عدم حفظ كلمة المرور نهائياً كـ نص عادي أو داخل ملفات التطبيق.
- احترام سياسات RLS وقواعد أمان قاعدة البيانات؛ الولي لا يرى إلا ملفات أطفاله حصراً.
- عدم طلب إعادة تسجيل الدخول إلا عند النقر اليدوي على «تسجيل الخروج» أو إلغاء الجلسة من الخادم.

### 3. إشعارات Android الحقيقية (Firebase Cloud Messaging)
- وصول الإشعارات في الحالات الثلاث:
  1. أثناء استخدام التطبيق (Foreground) عبر تنبيه فوري وشارات الواجهة.
  2. أثناء عمل التطبيق في الخلفية (Background).
  3. والتطبيق مغلق تماماً (Killed/Closed).
- ربط رمز FCM الخاص بكل هاتف بحساب الولي في جدول `parent_device_tokens` على Supabase، مع دعم تسجيل عدة هواتف للحساب نفسه.
- إرسال الإشعارات عبر بروتوكول **Firebase Cloud Messaging HTTP v1** الرسمي والمشفر من خلال دالة **Supabase Edge Function**.
- مشغلات قاعدة بيانات تلقائية تكتشف 4 أحداث رئيسية:
  1. وصول رسالة جديدة من الإدارة موجهة للولي أو لطفله.
  2. نشر تقرير متابعة بيداغوجي أو استمارة تقييم معتمدة.
  3. مشاركة ملف أو وثيقة جديدة تخص الطفل.
  4. نشر برنامج أو أنشطة تربوية جديدة لقسم الطفل.
- احترام تام لخصوصية شاشة القفل (`VISIBILITY_PRIVATE`) بصياغات عامة تمنع ظهور أي بيانات شخصية أو طبية حساسة على الشاشة المغلقة.
- منع تكرار الإشعارات نهائياً (Idempotency) باستخدام معرف فريد لكل حدث (`tag`).
- عند النقر على الإشعار، يفتح التطبيق مباشرة في التبويب المناسب (`#msgs`, `#reports`, `#evaluations`, `#programs`, `#docs`).
- عند تسجيل الخروج، يتم إلغاء تفعيل رمز هذا الجهاز فقط من قاعدة البيانات بأمان دون التأثير على أجهزة الولي الأخرى.

## 🛠️ دليل تشغيل وبناء التطبيق:

### الطريقة الأولى: البناء التلقائي عبر GitHub Actions (الأسهل والأسرع)
1. أنشئ مستودعاً جديداً ومستقلاً على حسابك في GitHub (مثال: `dar-el-ihsan-parents-android`).
2. ارفع محتويات هذا المجلد إلى المستودع.
3. توجه إلى تبويب **Settings > Secrets and variables > Actions** وأضف الأسرار التالية:
   - `GOOGLE_SERVICES_JSON`: محتوى ملف `google-services.json` الذي تحمله من منصة Firebase Console.
   - `KEYSTORE_BASE64` (اختياري للنسخة الموقعة Release): ملف الـ keystore مشفراً بـ base64.
   - `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` (اختياري).
4. بمجرد دفع التحديثات (Push) أو تشغيل سير العمل يدوياً من تبويب **Actions**، سيقوم خادم GitHub السحابي ببناء التطبيق وتقديم ملفات `app-debug.apk` و `app-release.apk` جاهزة للتنزيل المباشر.

### الطريقة الثانية: الفتح والبناء عبر Android Studio
1. شغّل برنامج **Android Studio** على حاسوبك.
2. اختر **Open** واختر مجلد `dar-el-ihsan-parents-android`.
3. ضع ملف `google-services.json` المستخرج من مشروعك في Firebase داخل مجلد `app/`.
4. اضغط على **Sync Project with Gradle Files**.
5. من القائمة العلوية اختر: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. فور اكتمال البناء ستجد ملف التثبيت المباشر في:
   `app/build/outputs/apk/debug/app-debug.apk`
